Nestor est un assistant open source pour tout le foyer : un seul agent sur un serveur à la maison,
joint à voix haute par des satellites, dans le chat de l’administration ou sur Telegram. Nestor est en
préversion : une version peut changer la configuration ou le journal sans migration.
