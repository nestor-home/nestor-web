Home Assistant apporte à Nestor **la présence** et **les appareils** qu’il expose aux assistants. Une
adresse et un jeton suffisent pour les deux.

## Mise en place

<Steps>

1. **Créer un jeton.** Profil › **Sécurité** › jeton d’accès longue durée.

2. **Exposer les appareils.** Ajoutez l’intégration **Model Context Protocol Server**, puis les entités
   dans **Paramètres › Assistants vocaux › Exposer**. La présence s’en passe.

3. **Ajouter les secrets** dans `.env`.

   ```ini
   HOME_ASSISTANT_URL=http://homeassistant.local:8123
   HOME_ASSISTANT_TOKEN=eyJ...
   ```

4. **Décommenter `home`** dans `nestor.yaml`.

   ```yaml
   home:
     kind: home-assistant
     url: ${HOME_ASSISTANT_URL}
     token: ${HOME_ASSISTANT_TOKEN}
     people:
       alex: person.alex # chaque identifiant du foyer, avec son entité personne
   ```

</Steps>

## Ce que Nestor voit et fait

| Quoi                          | D’où ça vient                                                                          | Clé                 |
| ----------------------------- | -------------------------------------------------------------------------------------- | ------------------- |
| Qui est là                    | l’entité `person.*` de chaque personne                                                 | `people`            |
| Dans quelle pièce est chacun  | un capteur de pièce par personne (Bermuda, ESPresense)                                 | `rooms`             |
| Quelles pièces sont occupées  | des capteurs rattachés à une pièce ; par défaut tout capteur d’occupation, de présence ou de mouvement | `occupancy_sensors` |
| Les appareils qu’il pilote    | les entités exposées aux assistants, par le serveur MCP de Home Assistant (`/api/mcp`) | aucune              |

## Actions sensibles

Une action sensible attend l’accord de la personne ([Locuteurs](/fr/docs/agent/speakers/)) : son
domaine, sa classe d’appareil ou son nom contient l’une de ces valeurs, casse ignorée :

| Clé              | Défaut                                    |
| ---------------- | ----------------------------------------- |
| `domains`        | `lock`, `alarm_control_panel`             |
| `device_classes` | `garage`, `gate`, `door`                  |
| `names`          | `lock`, `alarm`, `garage`, `gate`, `door` |

Lire un état ne l’est jamais. Une liste donnée remplace son défaut ; ajoutez les noms dans votre langue :

```yaml
home:
  kind: home-assistant
  # …
  sensitive:
    names: [lock, garage, door, porte, portail]
```
