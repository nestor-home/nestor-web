L’agent pense avec un modèle de langage de votre choix, hébergé ou local, par l’API Chat
Completions d’OpenAI, ou nativement pour Claude et Gemini. Choisissez-en un qui gère les appels
d’outils.

## Choisir un fournisseur

`nestor init` écrit un profil sous `models`, nommé `main`. Pour changer de fournisseur,
remplacez-le par un bloc ci-dessous et lancez `nestor check`. La clé va dans `.env`, en
`MODEL_API_KEY` ; les serveurs locaux n’en demandent pas.

Un modèle local répond plus lentement, et la voix le ressent en premier.

Avec Docker, un serveur de modèle sur l’hôte est à `http://host.docker.internal:<port>/v1`. Sous

`--host 0.0.0.0` pour llama.cpp.

## Rôles

Avec plusieurs profils, chaque rôle nomme celui qu’il utilise :

| Rôle                   | Ce qu’il fait                                                                  | Sans réglage                    |
| ---------------------- | ------------------------------------------------------------------------------ | ------------------------------- |
| `agent.spoken`         | répond à voix haute : les premiers mots doivent venir vite                     | `agent.written`                 |
| `agent.written`        | répond par écrit, où quelques secondes ne gênent pas                           | `agent.spoken`                  |
| `watches.model`        | trie le courrier entrant pour les veilles                                      | `agent.written`                 |
| `memory.consolidation` | résume chaque conversation une fois terminée                                   | `agent.written`                 |
| `agent.titles`         | titre chaque discussion de l’admin d’après son premier échange ; un petit modèle suffit | `agent.written`                 |
| `agent.transcription`  | écoute les messages vocaux                                                     | le seul modèle de transcription |
| `agent.speech`         | répond à un message vocal par un autre                                         | le seul modèle de synthèse      |
| `agent.images`         | dessine les images qu’on lui demande                                           | le seul modèle d’images         |

Un modèle rapide pour la voix, un plus solide pour le reste :

```yaml
models:
  quick:
    type: language
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: anthropic/claude-haiku-5.5
  deep:
    type: language
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: anthropic/claude-sonnet-5.5

agent:
  spoken: quick
  written: deep
```

## Modèle de secours

Quand un modèle échoue avant de répondre (fournisseur en panne, surchargé, clé refusée), son
`fallback` répond à sa place, dans tous les rôles du modèle, et le journal dit lequel a pris le
relais. Un modèle de secours peut avoir le sien, essayé à son tour. Il reçoit la requête sans les
images ni les documents qu’il ne sait pas lire.

```yaml
models:
  claude:
    type: language
    provider: anthropic
    api_key: ${ANTHROPIC_API_KEY}
    model: claude-sonnet-5-5
    fallback: gemini
  gemini:
    type: language
    provider: gemini
    api_key: ${GEMINI_API_KEY}
    model: gemini-flash-latest
```

Un modèle qui échoue après avoir commencé à répondre n’est pas remplacé : la réponse recommencerait.

## Recherche par le sens

Un modèle d’embedding permet à Nestor de retrouver ses souvenirs par le sens : « que mange
Léa ? » trouve « Léa est végétarienne ». Nommez un profil d’embedding dans `memory.embedder` :

```yaml
models:
  vectors:
    type: embedding
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: openai/text-embedding-3-small
    dimensions: 1536

memory:
  embedder: vectors
```

Tout point `/embeddings` compatible OpenAI convient. `dimensions` est la taille des vecteurs ;
avec `send_dimensions: true`, un modèle qui sait raccourcir ses vecteurs les rend à cette taille.
Pour un modèle qui attend un préfixe (`query: `), réglez `query_prefix` et `document_prefix`.
Changer de modèle réindexe en tâche de fond. Voir [Mémoire](/fr/docs/agent/memory/).

## Images

Avec un modèle d’images, Nestor dessine ce qu’on lui demande (« dessine un dragon pour la carte de
Léa ») et l’envoie avec sa réponse, là où la conversation montre les images : la discussion de
l’admin, Telegram. Une image demandée à voix haute dans une pièce reste dans le journal de l’admin.

```yaml
models:
  painter:
    type: image
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: google/gemini-2.5-flash-image
    endpoint: chat
```

`endpoint: images`, par défaut, parle à `/images/generations` (OpenAI, Gemini, serveurs locaux) ;
`chat` parle à Chat Completions, comme les modèles d’images d’OpenRouter. `size` fixe la taille quand
le modèle en prend une (`1024x1024`).

## Entendre et parler

`models` contient tous les modèles qu’utilise Nestor. Chacun dit son `type` et son `provider`, le
plugin qui sert ce type, et un réglage ne propose que les modèles de son type :

| Type          | Ce qu’il fait                                              | Nommé dans                                                         |
| ------------- | ---------------------------------------------------------- | ------------------------------------------------------------------ |
| language      | répond, à voix haute ou à l’écrit                          | `agent` ([Rôles](#rôles))                                          |
| embedding     | retrouve les souvenirs par le sens                         | `memory.embedder`                                                  |
| transcription | entend ce qu’on dit à un satellite, et les messages vocaux | `voice.transcription` d’un canal satellites, `agent.transcription` |
| speech        | donne sa voix à l’assistant                                | `voice.speech` d’un canal satellites, `agent.speech`               |
| speaker       | reconnaît qui parle                                        | `voices.embedder` ([Locuteurs](/fr/docs/agent/speakers/))          |
| image         | dessine les images qu’on lui demande                       | `agent.images` ([Images](#images))                                 |

Configurer la voix : [Canaux et voix](/fr/docs/channels/#voix).

## Réglages

Un modèle de langage `openai-compatible` accepte aussi :

- `extra_body`, fusionné dans chaque requête (routage, raisonnement) ;
- `read_timeout_s`, en secondes (30) ;
- `cache_control`, pour le cache de prompt du fournisseur, actif par défaut pour OpenRouter et
  Anthropic ;
- `vision: true` pour un modèle qui lit les images : il voit alors les photos envoyées.

Les modèles `anthropic` et `gemini` voient les images et lisent les PDF sans qu’on le dise, et
acceptent `extra_body` et `read_timeout_s` (60). Tout modèle de langage accepte un `fallback`
([Modèle de secours](#modèle-de-secours)).
