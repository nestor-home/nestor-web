Installez Nestor sur une machine qui reste allumée : ordinateur, mini PC ou Raspberry Pi.

## Choisir une voie

Paquet Python [`nestor-home`](https://pypi.org/project/nestor-home/) (3.12+), ou image
`ghcr.io/nestor-home/nestor` (amd64, arm64).

| Installer avec              | uv                                          | pip                                 | Docker                                   |
| --------------------------- | ------------------------------------------- | ----------------------------------- | ---------------------------------------- |
| Python                      | uv le télécharge au besoin                  | le vôtre, 3.12 ou plus              | dans l’image                             |
| Configuration, `.env`, état | le dossier où vous avez lancé `nestor init` | idem                                | le dossier monté sur `/data`             |
| Mise à jour                 | `uv tool upgrade nestor-home`               | `pip install -U nestor-home`        | `docker pull`, puis un nouveau conteneur |
| Pour                        | un essai, écrire des satellites             | un environnement que vous avez déjà | un serveur à la maison, toujours allumé  |

Le paquet seul ne fait que l’écrit ; l’image contient les deux extras. S’il en manque un, Nestor
s’arrête au démarrage et donne la commande à lancer.

| Extra      | Ajoute                                                 |
| ---------- | ------------------------------------------------------ |
| `voice`    | la voix temps réel des satellites                      |
| `voice-id` | [la reconnaissance de qui parle](/fr/docs/agent/speakers/) |

## Installer et lancer

<Tabs set="install" locale="fr">
<Tab set="install" choice="uv">

```bash
uv tool install 'nestor-home[voice]'   # ou nestor-home, sans la voix des satellites
mkdir nestor && cd nestor
nestor init
```

Remplissez les clés vides de `.env`, puis :

```bash
nestor check
nestor run
```

`nestor` lit `nestor.yaml` et `.env` dans le dossier courant, ou `-c <fichier>`.

</Tab>
<Tab set="install" choice="pip">

```bash
python3 -m venv ~/.venvs/nestor
~/.venvs/nestor/bin/pip install nestor-home
mkdir nestor && cd nestor
~/.venvs/nestor/bin/nestor init
```

Remplissez `.env`, puis `nestor check` et `nestor run`. Voix : `'nestor-home[voice]'`.

</Tab>
<Tab set="install" choice="docker">

Tout vit dans un dossier monté sur `/data` :

```bash docker-quickstart
docker run -it --rm -v ./nestor:/data ghcr.io/nestor-home/nestor init
$EDITOR nestor/.env
docker run -d --name nestor --restart unless-stopped -v ./nestor:/data -p 8470:8470 -p 8471:8471 ghcr.io/nestor-home/nestor
```

Le conteneur tourne sous l’uid 1000. Le port 8470 est l’administration, 8471 les satellites
(`admin.port` et le `port` du canal des satellites, plus `-p`).

Les autres commandes passent par l’image :

```bash
docker run --rm -v ./nestor:/data ghcr.io/nestor-home/nestor check
docker run --rm -it -v ./nestor:/data ghcr.io/nestor-home/nestor secrets list
```

Après avoir modifié `nestor/.env`, `docker restart nestor`. Un serveur de modèle local (Ollama,
LM Studio) est à `http://host.docker.internal:<port>/v1` ; sous Linux, ajoutez
`--add-host host.docker.internal:host-gateway`.

### Avec Compose

[`compose.yaml`](https://github.com/nestor-home/nestor/blob/main/compose.yaml) ajoute une réplique
Litestream facultative et garde tout dans `./data` :

```bash
curl -fsSLO https://raw.githubusercontent.com/nestor-home/nestor/main/compose.yaml
docker compose run --rm nestor init
docker compose up -d
```

Mise à jour : `docker compose pull`, puis `docker compose up -d`. Il suit `latest` ; fixez une ligne
avec `ghcr.io/nestor-home/nestor:<majeure>.<mineure>`.

</Tab>
</Tabs>

L’administration signale chaque version : [Mises à jour](/fr/docs/updates/).

## Le compte propriétaire

`nestor init` le crée. Sans compte (configuration écrite à la main, `state/` venu d’ailleurs) :

```bash
nestor accounts create-owner --login alex
```

`--person` choisit le membre (le premier par défaut). Redémarrez Nestor. Avec Docker, préfixez par
`docker run --rm -it -v ./nestor:/data ghcr.io/nestor-home/nestor`.
