[`nestor-satellite`](https://pypi.org/project/nestor-satellite/) gère l’appairage, le jeton, le
manifeste, le lien et le texte, sous Python 3.12 ou plus récent. L’audio et la caméra sont des
extras.

## Installer

<Steps>

1. **Installer le paquet**

   ```bash
   pip install 'nestor-satellite[voice,sounddevice]'   # a microphone and a speaker
   pip install nestor-satellite                        # a device that only writes
   ```

2. **L’appairer** avec l’URI d’appairage d’un code d’enrôlement, créé sous **Satellites**
   dans l’administration ou avec `nestor satellites add --room salon`. Les lancements suivants se
   reconnectent.

   ```bash
   nestor-satellite run --room salon --pairing-uri 'nestor+http://nestor.local:8471/?code=K7QF2M9X'
   ```

</Steps>

| Extra         | Ajoute                                                          |
| ------------- | --------------------------------------------------------------- |
| `voice`       | l’audio en WebRTC, et le code d’appareil dit à voix haute       |
| `sounddevice` | le micro et le haut-parleur de la machine (PortAudio)           |
| `video`       | une caméra filmée en WebRTC, et des photos                      |
| `opencv`      | une caméra lue par OpenCV (V4L2 sous Linux)                     |
| `qr`          | les URI d’appairage lues sur un QR code montré à la caméra      |

## La commande

`nestor-satellite run` fait de cette machine un satellite : son micro et son haut-parleur, son
terminal, ou les deux.

| Option              | Flag ou variable                        | Effet                                                                    |
| ------------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| Cœur                | `--core`                                | l’adresse du cœur, par exemple `http://nestor.local:8471` (par défaut : celle de l’URI d’appairage) |
| URI d’appairage     | `--pairing-uri`, `NESTOR_PAIRING_URI`   | appaire avec un code d’enrôlement créé dans Nestor                       |
| Code d’enrôlement   | `--pairing-code`, `NESTOR_PAIRING_CODE` | le même code seul, avec `--core`                                         |
| Pièce               | `--room`                                | la pièce où se trouve l’appareil (obligatoire)                           |
| Identifiant         | `--id`                                  | l’identifiant de l’appareil (par défaut : le nom de la machine)          |
| Jeton               | `--token-file`                          | où garder le jeton (par défaut : `~/.config/nestor-satellite/<id>.json`) |
| Texte               | `--text`                                | envoie les lignes tapées sur stdin, affiche les réponses                 |
| Sans voix           | `--no-voice`                            | retire le micro et le haut-parleur (aucun extra nécessaire)              |
| Cartes son          | `--input-device`, `--output-device`     | un périphérique PortAudio, par nom ou par numéro                         |
| Caméra              | `--camera`                              | filme quand une personne ouvre une session, lit les QR codes (`0` sous macOS, `/dev/video0` sous Linux ; extras `video` et `qr`) |
| Langue              | `--lang`                                | la langue parlée : `en` ou `fr` (par défaut : celle de l’environnement)  |
| Mises à jour        | `--managed`                             | une personne peut le mettre à jour depuis Nestor (voir [Mises à jour](#mises-à-jour)) |

Sans code d’enrôlement, il dit un code d’appareil sur son haut-parleur et l’écrit dans son journal :
tapez-le dans l’administration. `nestor-satellite run --help` liste toutes les options.

## Votre propre pilote

Une enceinte avec un micro, une lumière et une sortie texte :

```python
import asyncio

from nestor_satellite import EXPRESSION, IDENTIFY, Body, Device, Manifest, Satellite, TokenStore
from nestor_satellite.devices import Microphone, Speaker


class Led(Body):
    def behavior(self, behavior):
        print("attitude:", behavior)  # idle, listening, thinking, speaking

    def expression(self, expression, intensity):
        print("expression:", expression, intensity)

    def identify(self):
        print("blink!")  # a person is telling devices apart


satellite = Satellite(
    "http://nestor.local:8471",
    Manifest.of(Device("enceinte-salon", "raspberry-pi-4", "salon"), EXPRESSION, IDENTIFY),
    tokens=TokenStore("~/.config/nestor-satellite/enceinte-salon.json"),
    body=Led(),
    source=Microphone(),  # audio.capture, with the voice extra
    sink=Speaker(),  # audio.playback
    text_display=lambda text, final: print(text),  # text.display
    text_input=True,  # text.input: satellite.send_text("…")
)
asyncio.run(satellite.run())  # pairs the first time, then stays connected and reconnects
```

`run` se reconnecte quand le lien tombe et s’appaire de nouveau si son jeton est refusé. Il
s’arrête quand un lien plus récent du même appareil le remplace, et lève `PairingFailed` quand
réessayer ne sert à rien.

## Capacités

Le manifeste décrit le corps et les capteurs : `EXPRESSION`, `IDENTIFY`, `HEAD_MOTION`,
`PERSON_DETECTION`, `SPEECH_ACTIVITY`. Le reste découle des arguments ; le déclarer dans le
manifeste lève `ValueError`.

| Argument                                     | Déclare           |
| -------------------------------------------- | ----------------- |
| `text_display=` une fonction `(text, final)` | `text.display`    |
| `text_input=True`                            | `text.input`      |
| `source=` un `AudioSource` (`Microphone()`)  | `audio.capture`   |
| `sink=` un `AudioSink` (`Speaker()`)         | `audio.playback`  |
| `camera=` une `Camera`                       | `video.capture`   |
| `on_media=` une fonction `(active)`          | `media.indicator` |
| `updater=` un `Updater`                      | `device.update`   |

- `satellite.send_text("…")` envoie de 1 à 4 000 caractères tapés. Il renvoie `False` quand le
  lien est coupé et lève `CapabilityNotAllowed` si le foyer n’a pas autorisé `text.input`.
- `final` marque le dernier message d’une réponse.
- `ice_servers=` (des URL STUN ou TURN) ne sert qu’au-delà du réseau local.

## Options d’appairage

| Argument                                                              | Déclare                   |
| --------------------------------------------------------------------- | ------------------------- |
| toujours                                                              | `enrollment.provisioning` |
| `display=` un `Display` (`show(text, code)`, `clear()`)               | `device_code.display`     |
| `voice=` une fonction qui dit une phrase, ou un `sink` sans `display` | `device_code.speech`      |
| `enrolls_by=[PairingMethod.INPUT]`                                    | `enrollment.input`        |
| `camera=` une `Camera` (extra `qr`)                                   | `enrollment.qr`           |

- `enrollment=` prend une URI d’appairage ou un code d’enrôlement. Par défaut, il lit
  `NESTOR_PAIRING_URI`, puis `NESTOR_PAIRING_CODE`.
- `await satellite.enroll("K7QF-2M9X")` envoie un code tapé sur l’appareil. Il renvoie `ACCEPTED`,
  `REFUSED`, `NOT_PENDING` ou `INVALID`. Un code refusé n’est plus jamais envoyé.
- `locale="fr"` règle la langue dans laquelle il parle.

## Voix et caméra

Un micro et un haut-parleur portent la conversation à voix haute ([Voix](/fr/docs/voice/)). Avec
une caméra, les personnes autorisées peuvent regarder par l’appareil, et avec un micro et un
haut-parleur appeler par lui, seulement dans les sessions qu’elles ouvrent dans Nestor
([Caméras et appels](/fr/docs/satellites/cameras/)).

| Caméra            | Lit                                                       |
| ----------------- | --------------------------------------------------------- |
| `PiCamera()`      | la caméra du Raspberry Pi (Picamera2, fournie par le système) |
| `OpenCvCamera(0)` | une caméra par OpenCV (extra `opencv`)                    |
| `AvCamera(…)`     | une caméra par FFmpeg                                     |
| `PatternCamera()` | une mire, pour essayer                                    |

Le SDK applique lui-même les règles des sessions : il ne se connecte que quand son lien le demande,
termine la session quand on le lui dit, à sa limite de temps ou quand le lien tombe, et n’écoute
jamais sur un port. Nestor ne laisse filmer un appareil qu’en TLS (`https://`), ou sur la machine
du cœur.

## Mises à jour

Le manifeste nomme le logiciel que fait tourner l’appareil : `nestor-satellite` et sa version, sauf
si le pilote passe `software=Software.of("mon-satellite")` (sa version est lue dans le paquet
installé).

Un `Updater` trouve une version plus récente à sa source (`newer`), en installe une (`install`) et
peut donner le lien de ses notes (`notes`). `PypiUpdater("mon-satellite", module="mon_satellite")`
le fait pour les paquets installés depuis PyPI avec uv ou pip. Sans updater, l’administration
montre seulement la version.

`nestor-satellite run --managed` se met à jour de la même façon : il installe la version demandée
par une personne dans son propre environnement, puis relance sa commande. Si la nouvelle version
n’est pas accueillie dans les 60 s, il revient à la précédente. Lancez-le quand même sous un
gestionnaire de services. Les règles : [Mises à jour](/fr/docs/satellites/protocol/#10-mises-à-jour)
dans le protocole.

## Conformité

Lancez la suite du serveur contre la commande de votre pilote, sans carte son. Avec la commande du
[modèle Python](/fr/docs/sdks/templates/) :

```bash
uvx --from 'nestor-home[voice]==<version>' nestor satellites conformance -- \
  my-satellite run --core {url} --room salon --token-file {state}/token.json --null-audio
```

[Conformité](/fr/docs/satellites/conformance/) explique les marqueurs et le rapport. Le code et la
licence des enregistrements de voix sont dans
[nestor-satellite-python](https://github.com/nestor-home/nestor-satellite-python) ; un pilote
complet : [nestor-reachy](https://github.com/nestor-home/nestor-reachy).
