La crate [`nestor-satellite`](https://crates.io/crates/nestor-satellite) gère l’appairage, le
jeton, le manifeste, le lien et le texte. Elle se construit avec Rust 1.91 ou plus récent et un
compilateur C. L’audio et la caméra sont des fonctionnalités (features).

## Installer

<Steps>

1. **Installer la commande**, ou prendre un binaire pour macOS ou Linux dans une
   [release](https://github.com/nestor-home/nestor-satellite-rust/releases) :

   ```bash
   cargo install nestor-satellite --features cli
   ```

2. **L’appairer** avec l’URI d’appairage d’un code d’enrôlement, créé sous **Satellites**
   dans l’administration ou avec `nestor satellites add --room salon`. Les lancements suivants se
   reconnectent.

   ```bash
   nestor-satellite run --room salon --pairing-uri 'nestor+http://nestor.local:8471/?code=K7QF2M9X'
   ```

</Steps>

Dans un pilote, ajoutez la crate avec les fonctionnalités dont il a besoin :

```bash
cargo add nestor-satellite --features audio
cargo add tokio --features macros,rt-multi-thread
```

| Fonctionnalité | Ajoute                                                                                 |
| -------------- | -------------------------------------------------------------------------------------- |
| par défaut     | l’appairage, le lien, les intentions, les observations, le texte : sans WebRTC         |
| `voice`        | l’audio en WebRTC (Opus) avec vos propres `AudioSource` et `AudioSink`, le code d’appareil dit à voix haute, les appels ; demande `cmake` |
| `audio`        | `voice` avec le micro et le haut-parleur de la machine (cpal) ; sous Linux, ALSA (`apt install libasound2-dev pkg-config`) |
| `video`        | `voice` avec une `Camera` filmée en VP8 (en Rust pur), et des photos en JPEG           |
| `cli`          | la commande `nestor-satellite` (`audio` et `video`)                                    |

## La commande

`nestor-satellite run` fait de cette machine un satellite : son micro et son haut-parleur, son
terminal, ou les deux.

| Option            | Flag ou variable                        | Effet                                                                    |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| Cœur              | `--core`, `NESTOR_CORE`                 | l’adresse du cœur, par exemple `http://nestor.local:8471` (par défaut : celle de l’URI d’appairage) |
| URI d’appairage   | `--pairing-uri`, `NESTOR_PAIRING_URI`   | appaire avec un code d’enrôlement créé dans Nestor                       |
| Code d’enrôlement | `--pairing-code`, `NESTOR_PAIRING_CODE` | le même code seul, avec `--core`                                         |
| Pièce             | `--room`                                | la pièce où se trouve l’appareil (obligatoire)                           |
| Identifiant       | `--id`                                  | l’identifiant de l’appareil (par défaut : le nom de la machine)          |
| Jeton             | `--token-file`                          | où garder le jeton (par défaut : `~/.config/nestor-satellite/<id>.json`) |
| Texte             | `--text`                                | envoie les lignes tapées sur stdin, affiche les réponses                 |
| Texte seul        | `--text-only`                           | l’écrit seul : ni micro, ni haut-parleur, ni WebRTC                      |
| Cartes son        | `--input-device`, `--output-device`     | une partie du nom d’un périphérique (`nestor-satellite devices` les liste) |
| Sans carte son    | `--null-audio`                          | envoie du silence et ignore la voix du cœur                              |
| STUN ou TURN      | `--ice-server`                          | un serveur, répétable ; ne sert qu’au-delà du réseau local               |
| Caméra            | `--camera`                              | filme quand une personne ouvre une session : `/dev/video0` (Linux) ou `test-pattern` |
| Langue            | `--language`                            | la langue parlée : `en` ou `fr` (par défaut : d’après `LANG`)            |

Sans code d’enrôlement, il dit un code d’appareil sur son haut-parleur et l’écrit dans son journal :
tapez-le dans l’administration. `nestor-satellite run --help` liste toutes les options.

## Votre propre pilote

Une enceinte avec un micro et une lumière (fonctionnalité `audio`) :

```rust
use nestor_satellite::devices::{Microphone, Speaker};
use nestor_satellite::{Behavior, Body, Device, IDENTIFY, Manifest, Satellite, TokenStore};

struct Led;
impl Body for Led {
    fn behavior(&self, behavior: Behavior) {
        println!("attitude: {behavior}"); // light the ring, from a task of its own
    }
    fn identify(&self) {
        println!("blink"); // a person looks for this device: blink for a few seconds
    }
}

#[tokio::main]
async fn main() -> nestor_satellite::Result<()> {
    let device = Device::new("enceinte-salon", "raspberry-pi-4", "salon")?;
    let manifest = Manifest::new(device, [IDENTIFY])?;
    let tokens = TokenStore::new("~/.config/nestor-satellite/enceinte-salon.json");
    let satellite = Satellite::builder("http://nestor.local:8471", manifest, tokens).body(Led);
    // The microphone declares audio.capture, the speaker audio.playback.
    satellite.source(Microphone::new()).sink(Speaker::new()).build()?.run().await // pairs once, then reconnects
}
```

`run` se reconnecte quand le lien tombe et s’appaire de nouveau si son jeton est refusé. Il
renvoie `Error::Replaced` quand un lien plus récent du même appareil prend le relais. L’API est sur
[docs.rs](https://docs.rs/nestor-satellite).

## Capacités

Le manifeste décrit le corps et les capteurs : `EXPRESSION`, `IDENTIFY`, `HEAD_MOTION`,
`PERSON_DETECTION`, `SPEECH_ACTIVITY`. Le reste découle du builder ; le déclarer dans le manifeste
sans lui fait échouer `build` avec `Error::NotProvided`.

| Builder                                                 | Déclare                              |
| ------------------------------------------------------- | ------------------------------------ |
| `.text_display(…)`, un `TextDisplay` ou `Fn(&str, bool)` | `text.display`                      |
| `.text_input()`                                         | `text.input`                         |
| `.source(…)`, un `AudioSource` (`voice`)                | `audio.capture`                      |
| `.sink(…)`, un `AudioSink` (`voice`)                    | `audio.playback`                     |
| `.null_audio()` (`voice`)                               | les deux, sans carte son (tests)     |
| `.camera(…)`, une `Camera` (`video`)                    | `video.capture`                      |
| `.media_indicator(…)`                                   | `media.indicator`                    |
| `.updater(…)`, un `Updater`                             | `device.update`                      |

- `satellite.observer().input_text(…)` envoie de 1 à 4 000 caractères tapés. Il renvoie
  `Ok(false)` quand le lien est coupé, et `Error::CapabilityNotAllowed` si le foyer n’a pas
  autorisé `text.input`.
- `last` marque le dernier message d’une réponse.
- `.ice_servers(…)` ne sert qu’au-delà du réseau local.

## Options d’appairage

| Builder                                                                                         | Déclare                   |
| ----------------------------------------------------------------------------------------------- | ------------------------- |
| toujours (`.enrollment(Enrollment::parse(…)?)`, ou `NESTOR_PAIRING_URI` / `NESTOR_PAIRING_CODE`) | `enrollment.provisioning` |
| `.display(…)`, un `Display` (`show_code`, `show_message`, `clear`)                              | `device_code.display`     |
| un `.sink(…)` sans écran, ou `.voice(…)`                                                        | `device_code.speech`      |
| `.accepts_enrollment(EnrollmentMethod::Input)`, codes passés à `satellite.enroller()`           | `enrollment.input`        |

- Un code d’enrôlement refusé n’est plus jamais envoyé.
- Ce SDK ne lit aucun QR code : pas d’`enrollment.qr`.
- `.language(…)` règle la langue dans laquelle il parle (par défaut : `LANG`).

## Voix et caméra

La fonctionnalité `voice` porte la conversation à voix haute ([Voix](/fr/docs/voice/)). Avec
`video`, les personnes autorisées peuvent regarder par l’appareil, et avec un micro et un
haut-parleur appeler par lui, seulement dans les sessions qu’elles ouvrent dans Nestor
([Caméras et appels](/fr/docs/satellites/cameras/)).

`Camera` est un trait. `V4l2Camera::new("/dev/video0")` lit une caméra sous Linux (une webcam, ou la
caméra du Raspberry Pi par son pilote V4L2), `.with_size(1280, 720)` règle sa taille, et
`TestPattern::default()` dessine des barres de couleur pour essayer. Le SDK applique lui-même les
règles des sessions et n’écoute jamais sur un port. Nestor ne laisse filmer un appareil qu’en TLS
(`https://`), ou sur la machine du cœur.

## Mises à jour

Le manifeste nomme le logiciel que fait tourner l’appareil : la crate `nestor-satellite` et sa
version, sauf si `Manifest::with_software(Software::new(…)?)` nomme le paquet sous lequel un pilote
est publié.

Un `Updater` passé à `.updater(…)` trouve une version plus récente à sa source (`newer`) et
l’installe (`install`). L’appareil signale les nouvelles versions une fois connecté puis une fois
par jour, n’installe que celle qu’il a trouvée, et revient en arrière si la nouvelle n’est pas
accueillie dans les 60 s. Une fois installée, le même programme redémarre avec les mêmes arguments
(Unix), sauf si `.restart(…)` en décide autrement. Sans updater, l’administration montre seulement
la version. Les règles : [Mises à jour](/fr/docs/satellites/protocol/#10-mises-à-jour) dans le
protocole.

## Conformité

Lancez la suite du serveur contre la commande, sans carte son :

```bash
uvx --from 'nestor-home[voice]==<version>' nestor satellites conformance -- \
  nestor-satellite run --core {url} --room salon --null-audio --token-file {state}/token.json
```

[Conformité](/fr/docs/satellites/conformance/) explique les marqueurs et le rapport. Le code, ses
exemples et la licence des enregistrements de voix sont dans
[nestor-satellite-rust](https://github.com/nestor-home/nestor-satellite-rust).
