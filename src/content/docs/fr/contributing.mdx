Tous les dépôts de [nestor-home](https://github.com/nestor-home) suivent le guide
[CONTRIBUTING](https://github.com/nestor-home/.github/blob/main/CONTRIBUTING.md) ; leurs `README.md`
et `AGENTS.md` donnent installation et vérifications.

## Proposer un changement

<Steps>

1. **Ouvrir une pull request**

   Un seul changement, avec ses tests et sa documentation. Les tests vérifient un comportement réel.

2. **Lui donner un titre**

   Il devient le commit fusionné : [Conventional Commits](https://www.conventionalcommits.org/)
   (`feat: …`, `fix: …`, `!` pour un changement cassant).

3. **La fusionner**

   Quand sa vérification `ci` est au vert.

</Steps>

## Versions

release-please garde ouverte une pull request de release ; la fusionner étiquette et publie. Avant
la 1.0, un `feat` ou un changement cassant monte la version mineure, tout le reste le correctif.

| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| [nestor](https://github.com/nestor-home/nestor)                                           | `nestor-home` sur PyPI, `ghcr.io/nestor-home/nestor`         |
| [nestor-satellite-python](https://github.com/nestor-home/nestor-satellite-python)         | `nestor-satellite` sur PyPI                                  |

## Signaler

| Quoi                  | Où                                                                                       |
| --------------------- | ---------------------------------------------------------------------------------------- |
| questions et idées    | les [Discussions](https://github.com/orgs/nestor-home/discussions)                       |
| un bug reproductible  | les issues du dépôt                                                                      |
| une vulnérabilité     | la [politique de sécurité](https://github.com/nestor-home/.github/blob/main/SECURITY.md) |

## Licence et langues

Le serveur, les SDK, le satellite Reachy et le personnage sont sous licence MIT.

Nestor parle anglais et français ; chaque phrase destinée aux personnes est un message
[Project Fluent](https://projectfluent.org/), jamais dans le code.

| Catalogues de       | Dossier                          |
| ------------------- | -------------------------------- |
| le serveur          | `src/nestor/locales/<langue>/`   |
| l’administration    | `web/src/locales/<langue>/`      |
| ce site             | `src/locales/<langue>/`          |

Une nouvelle langue est un nouveau dossier.
