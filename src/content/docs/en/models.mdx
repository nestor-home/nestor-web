The agent thinks with a language model you choose, hosted or local, through the OpenAI Chat
Completions API. Pick one that supports tool calls.

## Choose a provider

`nestor init` writes one profile under `models`, named `main`. To change provider, replace it with
a block below and run `nestor check`. The key goes in `.env` as `MODEL_API_KEY`; local servers need
none.

Any model with tool calls works. A local model answers more slowly, and the voice feels it first.

With Docker, reach a model server on the host at `http://host.docker.internal:<port>/v1`. On Linux,
make it listen on all interfaces: `OLLAMA_HOST=0.0.0.0` for Ollama, `--host 0.0.0.0` for llama.cpp.

## Roles

With several profiles, each role names the one it uses:

| Role                   | What it does                                     | When unset      |
| ---------------------- | ------------------------------------------------ | --------------- |
| `agent.spoken`         | answers aloud: the first words must come fast    | `agent.written` |
| `agent.written`        | answers in writing, where a few seconds are fine | `agent.spoken`  |
| `watches.model`        | sorts incoming mail for the watches              | `agent.written` |
| `memory.consolidation` | summarizes each conversation once it is over     | `agent.written` |

A fast model for the voice, a stronger one for the rest:

```yaml
models:
  quick:
    type: language
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: anthropic/claude-haiku-5.5
  deep:
    type: language
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: anthropic/claude-sonnet-5.5

agent:
  spoken: quick
  written: deep
```

## Search by meaning

An embedding model lets Nestor find memories by meaning: “what does Léa eat?” finds “Léa is
vegetarian”. Name an embedding profile in `memory.embedder`:

```yaml
models:
  vectors:
    type: embedding
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: openai/text-embedding-3-small
    dimensions: 1536

memory:
  embedder: vectors
```

Any OpenAI-compatible `/embeddings` endpoint works. `dimensions` is the vector size. For a model
that expects a prefix (`query: `), set `query_prefix` and `document_prefix`. Changing the model reindexes in the background. See [Memory](/docs/agent/memory/).

## Hearing and speaking

`models` holds every model Nestor uses. Each one says its `type` and its `provider`, the plugin
that serves that type, and a setting only offers the models of its type:

| Type          | What it does                         | Named in                                              |
| ------------- | ------------------------------------ | ----------------------------------------------------- |
| language      | answers, aloud or in writing         | `agent` ([Roles](#roles))                             |
| embedding     | finds memories by meaning            | `memory.embedder`                                     |
| transcription | hears what people say to a satellite | a satellites channel's `voice.transcription`          |
| speech        | gives the assistant its voice        | a satellites channel's `voice.speech`                 |
| speaker       | knows who is speaking                | `voices.embedder` ([Speakers](/docs/agent/speakers/)) |

Setting up the voice: [Channels and voice](/docs/channels/#voice).

## Settings

A chat profile also takes:

- `extra_body`, merged into every request (routing, reasoning);
- `read_timeout_s`, in seconds (30);
- `cache_control`, for the provider’s prompt cache, on by default for OpenRouter and Anthropic.
