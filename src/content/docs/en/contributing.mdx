Every [nestor-home](https://github.com/nestor-home) repository follows the organization’s
[CONTRIBUTING](https://github.com/nestor-home/.github/blob/main/CONTRIBUTING.md). Each repository’s
`README.md` and `AGENTS.md` explain its setup and checks.

## Make a change

<Steps>

1. **Open a pull request**

   One pull request is one change, with its tests and documentation. Tests check real behaviour.

2. **Title it**

   The title becomes the squashed commit, so it follows
   [Conventional Commits](https://www.conventionalcommits.org/): `feat: …`, `fix: …`. A breaking
   change adds `!`.

3. **Merge it**

   It is merged once its `ci` check is green.

</Steps>

## Releases

release-please keeps a pull request open with the next version and its changelog. Merging it tags
and publishes the release. Before 1.0, a `feat` or a breaking change raises the minor version,
anything else the patch.

## Reporting

| What                 | Where                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------- |
| questions and ideas  | [Discussions](https://github.com/orgs/nestor-home/discussions)                          |
| a reproducible bug   | the repository’s issues                                                                 |
| a vulnerability      | the [security policy](https://github.com/nestor-home/.github/blob/main/SECURITY.md)     |

## Licence and languages

The server, the SDKs, the Reachy satellite and the character are under the MIT licence.

Nestor speaks English and French. What it says to people is never in the code: each sentence is a
[Project Fluent](https://projectfluent.org/) message.

| Catalogues of       | Folder                            |
| ------------------- | --------------------------------- |
| the server          | `src/nestor/locales/<language>/`  |
| the admin           | `web/src/locales/<language>/`     |
| this site           | `src/locales/<language>/`         |

Another language starts as another folder of catalogues.
