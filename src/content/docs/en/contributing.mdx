Every [nestor-home](https://github.com/nestor-home) repository follows the
[CONTRIBUTING](https://github.com/nestor-home/.github/blob/main/CONTRIBUTING.md) guide; its
`README.md` and `AGENTS.md` give its setup and checks.

## Make a change

<Steps>

1. **Open a pull request**

   One change, with its tests and documentation. Tests check real behaviour.

2. **Title it**

   It becomes the squashed commit: [Conventional Commits](https://www.conventionalcommits.org/)
   (`feat: …`, `fix: …`, `!` for a breaking change).

3. **Merge it**

   Once its `ci` check is green.

</Steps>

## Releases

release-please keeps a release pull request open; merging it tags and publishes. Before 1.0, `feat`
or a breaking change raises the minor version, anything else the patch.

| Repository                                                                                | Published as                                                |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| [nestor](https://github.com/nestor-home/nestor)                                           | `nestor-home` on PyPI, `ghcr.io/nestor-home/nestor`         |
| [nestor-satellite-python](https://github.com/nestor-home/nestor-satellite-python)         | `nestor-satellite` on PyPI                                  |
| [nestor-satellite-typescript](https://github.com/nestor-home/nestor-satellite-typescript) | `@nestor-home/satellite` on npm                             |
| [nestor-satellite-rust](https://github.com/nestor-home/nestor-satellite-rust)             | `nestor-satellite` on crates.io, its CLI on GitHub Releases |
| [nestor-reachy](https://github.com/nestor-home/nestor-reachy)                             | `nestor-reachy` on PyPI                                     |
| [nestor-character](https://github.com/nestor-home/nestor-character)                       | `@nestor-home/character` on npm                             |
| [nestor-web](https://github.com/nestor-home/nestor-web)                                   | this site                                                   |

## Reporting

| What                 | Where                                                                                   |
| -------------------- | --------------------------------------------------------------------------------------- |
| questions and ideas  | [Discussions](https://github.com/orgs/nestor-home/discussions)                          |
| a reproducible bug   | the repository’s issues                                                                 |
| a vulnerability      | the [security policy](https://github.com/nestor-home/.github/blob/main/SECURITY.md)     |

## Licence and languages

The server, the SDKs, the Reachy satellite and the character are MIT-licensed.

Nestor speaks English and French; every sentence for people is a
[Project Fluent](https://projectfluent.org/) message, never in the code.

| Catalogues of       | Folder                            |
| ------------------- | --------------------------------- |
| the server          | `src/nestor/locales/<language>/`  |
| the admin           | `web/src/locales/<language>/`     |
| this site           | `src/locales/<language>/`         |

A new language is a new folder.
