A satellite is a device paired with the Nestor server: a speaker, a wall tablet, a robot like
Reachy Mini, a browser tab, a terminal, a camera. People type on it, talk to it, or both. It
connects to the `satellites` channel on port 8471, which needs a [voice](/docs/voice/) to talk
aloud.

## How it works

A satellite pairs once, declares its capabilities, then holds a WebSocket to the server. Audio goes
over WebRTC.

The server sends intents, not motions. Given `intent.expression` with `joy`, a robot moves its
antennas; a plain speaker never gets it, since it did not declare `expression.emotion`.

## Capabilities

The device declares what it can do and a person allows it. All are optional.

| Capability                | The device…                                             |
| ------------------------- | ------------------------------------------------------- |
| `text.input`              | sends what a person typed                               |
| `text.display`            | shows the assistant’s answers                           |
| `audio.capture`           | sends its microphone to the server                      |
| `audio.playback`          | plays the server’s voice                                |
| `audio.speech_activity`   | reports when someone starts and stops speaking          |
| `vision.person_detection` | reports a person it sees                                |
| `expression.emotion`      | shows an emotion (`intent.expression`)                  |
| `motion.head`             | moves its head with the beats of speech (`intent.beat`) |
| `device.identify`         | makes itself noticed when a person looks for it         |
| `device.update`           | installs a newer version of its software when asked     |
| `video.capture`           | films, in the sessions a person opens                   |
| `media.indicator`         | shows that it films or is in a call                     |

Filming and calls have their own page: [Cameras and calls](/docs/satellites/cameras/).

## Pairing

A person proves they meant to pair the device, with one of two codes:

- a **device code**: six digits the device presents, typed in the admin;
- an **enrollment code** made in the admin (`K7QF-2M9X`), given to the device, usually as a
  pairing URI: `nestor+http://nestor.local:8471/?code=K7QF2M9X`.

| Method                    | The person…                                                                  |
| ------------------------- | ---------------------------------------------------------------------------- |
| `device_code.display`     | reads the code on the device’s screen and types it in the admin              |
| `device_code.speech`      | hears the device say its code and types it in the admin                      |
| `enrollment.input`        | types the enrollment code on the device                                      |
| `enrollment.provisioning` | puts the pairing URI in the device’s configuration (flag, environment, file) |
| `enrollment.qr`           | shows the pairing URI’s QR code to the device’s camera                       |

Every device supports `enrollment.provisioning`. The SDKs declare the others from the hardware.

## Add a satellite

<Steps>

1. **Start an addition**

   In the admin, open **The house**, then **Add a satellite**, and pick a method. Or, from the
   command line while Nestor runs:

   ```bash
   nestor satellites add --room salon --name "Living room speaker"   # prints the code and the pairing URI
   ```

2. **Give the device its proof**

   With an enrollment code, give the device its URI:

   ```bash
   NESTOR_PAIRING_URI='nestor+http://nestor.local:8471/?code=K7QF2M9X' nestor-satellite run --room salon
   ```

   With a device code, type the code the device presents. **Identify** makes a waiting device blink
   or chime, to tell devices apart.

   ```bash
   nestor satellites approve 042917                                       # the code the device presents
   nestor satellites approve 042917 --only audio.capture,audio.playback   # grants fewer capabilities
   ```

</Steps>

To unpair a device: `nestor satellites revoke enceinte-salon`.

## Updates

A satellite allowed `device.update` is updated from its page in the admin. See
[Updates](/docs/updates/#update-a-satellite).
