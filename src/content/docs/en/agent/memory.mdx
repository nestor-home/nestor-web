Nestor keeps **memories**, lasting facts ("Léa is vegetarian"), and **episodes**, what each past
conversation was about. Both are rebuilt from the journal. Memory is generous: a skipped line costs
little, a missing memory costs a wrong answer.

## What a turn carries

<MemoryTurn locale="en" n={1} />

The latest memories are dated, so the model keeps the later of two that disagree, and cached with
the household layer. The turn layer adds older ones the speaker's last three messages find, and the
speaker's episodes, which only their participants see. Tools reach the rest:

| Tool                | Does                                                                   |
| ------------------- | ---------------------------------------------------------------------- |
| `recall`            | searches memories and past conversations, between two dates if asked   |
| `read_conversation` | rereads one conversation word for word                                 |
| `remember`          | keeps a memory                                                         |
| `correct_memory`    | fixes one                                                              |
| `forget`            | drops one                                                              |

## Finding by words and by meaning

<HybridSearch locale="en" n={2} />

**By words**, SQLite's full-text index ranks matches, accents ignored. **By meaning**, an embedding
model turns the question into a vector and [sqlite-vec](https://github.com/asg017/sqlite-vec)
returns the nearest. Reciprocal rank fusion merges both lists. Search by meaning is optional: point
`memory.embedder` at an embedding model.

```yaml
models:
  embed:
    type: embedding
    provider: openai-compatible
    base_url: https://openrouter.ai/api/v1
    api_key: ${MODEL_API_KEY}
    model: openai/text-embedding-3-small
memory:
  embedder: embed
```

Any OpenAI-compatible embeddings server works, local ones included (llama.cpp's
`llama-server --embeddings`). Vectors are computed, and recomputed after a model change, in the
background.

## When a conversation is over

<Consolidation locale="en" n={3} />

Once a conversation's silence outlasts every medium of its place, the consolidation model writes
its episode (a few sentences and topics) and keeps the lasting facts the agent missed. After a
stop, Nestor catches up at the next start.

## Settings

| Setting                  | Default         | What it does                                                    |
| ------------------------ | --------------- | --------------------------------------------------------------- |
| `memory.strategy`        | `both`          | `recent`: the latest only; `search`: only what the words find   |
| `memory.recent`          | 150             | memories in the household layer                                 |
| `memory.found`           | 12              | memories the words may add beyond them                          |
| `memory.recent_episodes` | 3               | latest conversations of whoever speaks                          |
| `memory.found_episodes`  | 4               | older conversations their words may add                         |
| `memory.embedder`        | none            | the embedding model, for search by meaning                      |
| `memory.query_timeout_s` | 1               | seconds to embed a question before searching by words only      |
| `memory.consolidation`   | `agent.written` | the model that writes episodes                                  |
