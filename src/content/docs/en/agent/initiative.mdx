## What calls for it

| Source       | Example                                   | Tool                                       |
| ------------ | ----------------------------------------- | ------------------------------------------ |
| **Reminder** | "every weekday at 8, tell me the weather" | `schedule`                                 |
| **Watch**    | "tell me when the bank writes"            | `create_watch`                             |
| **Task**     | "read this PDF and sum up the contract"   | `delegate_task`, to an [executor](/docs/executors/) |
| **Message**  | "ask Léa if she needs the car"            | `message_person`                           |

Each has a short title, shown in the admin, and reaches whoever asked for it.

- **Reminder**: an instruction run at a time, once or on chosen days, with the agent's tools. A
  recurring one keeps a thread and tells only what changed. One missed during a stop runs once at
  the next start.
- **Watch**: a small model reads each incoming item once against all watches: mail from a
  [connected account](/docs/accounts/), a feed entry, a page change, a webhook
  ([Tools](/docs/tools/)).
- **Task**: its result is announced once, even after a restart, with the files it made.
- **Message**: one that expects a reply opens a question both people see until it is answered.
  `may_message` lists whom a person may write to through the agent: everyone by default (`"*"`),
  and always themselves.

## Where it arrives

The **courier** decides and journals the reason. Presence comes from
[Home Assistant](/docs/home/).

| The person                    | Nestor                                                        |
| ----------------------------- | ------------------------------------------------------------- |
| asked for writing, or is away | writes where they read (their `reach`)                        |
| is in a room with a satellite | speaks there                                                  |
| is home, in no known room     | speaks through `initiative.main_room`                         |
| is in a room without one      | writes                                                        |
| has no presence at all        | writes; speaks only into an ongoing spoken conversation, or to someone with nowhere to write |

| Case            | Then                                                                                  |
| --------------- | ------------------------------------------------------------------------------------- |
| no reaction     | a spoken message follows in writing after `initiative.follow_up_after_s` (180 s)       |
| quiet hours     | `initiative.quiet_hours` (`"22:30-07:30"`): nothing spoken unless urgent, still written |
| private content | the room hears that something came; the content is written                            |
| files           | written with the files; the room hears what they bring                                 |

A spoken message is heard by everyone in the room ([Speakers](/docs/agent/speakers/)).

## How it ends

Only the agent's final answer goes out, never "let me check". The journal records one of three
outcomes:

| Outcome         | When                                                | Then                                   |
| --------------- | --------------------------------------------------- | -------------------------------------- |
| passed on       | it reached the person                               | it stays in the conversation's history |
| nothing to tell | a check found nothing new                           | nothing sent, the reason journaled, never retried |
| not passed on   | no channel took it, or the model could not write it | tried again at the next start          |

Only what Nestor starts itself (a reminder, a watch) may end with nothing to tell. A request, a
message to pass on, a confirmation and a failure are always told.
